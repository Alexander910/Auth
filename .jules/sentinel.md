## 2025-05-22 - Mass Assignment Privilege Escalation in User Registration
**Vulnerability:** The registration endpoint (`/register`) accepted any request body parameters and passed them directly to the `AuthService.register` method, which subsequently passed them to `UserService.createUser`. This allowed clients to set their own `role` property (e.g., `role: "admin"`) during registration, resulting in privilege escalation.
**Learning:** Destructuring and passing parameters blindly without strict validation or whitelisting can lead to mass assignment. The controller must strictly destructure only the intended parameters (`name`, `email`, `password`) from `req.body` and ignore any others, while the service should enforce safe default values and avoid accepting arbitrary properties.
**Prevention:** Always use explicit destructuring of request bodies to limit input parameters to a safe and predefined whitelist. Avoid passing unvetted objects directly to persistence models.
